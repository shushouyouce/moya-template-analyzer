# 简称、黑话与获客阶段

## 简称判断原则

简称必须结合相邻词和素材内容判断。能确定才标准化；有多个含义时保留原词并标记待确认。

| 原始词 | 标准词 | 判断提示 |
| --- | --- | --- |
| cy、CY | 创业 | 与兼职、副业、电商同现时通常指创业 |
| cy用品 | 成人用品 | 这里的cy不是创业 |
| jz、JZ | 兼职 | 与创业同现可标为创业／兼职人群 |
| nk、NK | 男性健康 | 对外不使用简称，属于高合规领域 |
| PE、ED | 男性健康具体问题 | 作为需求词，不单建一级赛道 |
| s、S、s粉、se、色粉 | 敏感流量人群 | 必须结合正文，做高风险标记 |
| FK、复刻包 | 复刻商品 | 可能涉及仿品和商标风险，人工审核 |
| 女粉、男粉、宝妈粉 | 女性、男性、宝妈人群 | 是人群，不是赛道 |
| 创业粉、兼职粉、负债粉 | 创业、兼职、负债人群 | “粉”表示想吸引的受众 |
| 搭子、扩列 | 轻社交需求 | 结合同城、学习、旅游等场景细分 |
| 替换打法、替换养号 | 结构迁移打法 | 保留机制，替换人群、场景、痛点和承接 |
| 软广 | 原生广告内容 | 广告感较弱，但真实性和合规要求不变 |
| 小国、yc、yw s、定制v | 待确认 | 不猜含义，等待内部确认 |

错别字需统一，例如“情感符合”改为“情感复合”，“债w逾期”改为“债务逾期”，“代理记帐”改为“代理记账”。

## 获客阶段

每份模板选择一个主要阶段；跨越两个相邻环节时可以增加一个辅助阶段。

- S0｜赛道与账号定位：确定行业、受众、身份、产品和账号方向。
- S1｜账号冷启动：账号包装、首批内容、初始标签和基础流量。
- S2｜内容生产与测试：测试选题、开头、结构、表现形式或批量生产。
- S3｜涨粉与流量获取：带来观看、互动、关注、搜索或目标人群曝光。
- S4｜留资与私域承接：进入私信、表单、企微、社群或咨询入口。
- S5｜成交转化：购买商品、付费咨询、报课、加盟、招商或签约。
- S6｜交付与复购：服务交付、打卡、案例、续费、复购或转介绍。

## 容易误判的边界

- 评论多通常先归S3，只有明确进入咨询入口或留下联系方式才考虑S4。
- 主页有微信、橱窗或团购，只能说明存在承接入口，不能证明作品已经转化。
- 案例内容可能用于S3建立信任，也可能用于S5成交；看作品里是否出现明确购买或咨询动作。
- 讲课程内容不等于S6交付；只有面向已付费用户的教学、打卡或服务才是交付。
- “养号、提高权重”先识别为S1，但要区分正常账号准备与违规操纵平台行为。
